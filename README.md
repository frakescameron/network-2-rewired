network 2 rewired is a lightweight, terminal-triggered game built directly into Cam-OS

This project marks a shift from visual scripting (Blueprints) that i am used to using to a code-first approach, focusing on performance, simplicity, and full control over game logic.

🚀 Overview

Game is designed to be:

Fast — minimal overhead, no heavy engine dependencies
Responsive — optimized for smooth interaction without taxing system resources
Integrated — seamlessly embedded into the Cam-OS environment
Code-driven — built primarily using .jsx for structure and logic

🧠 Purpose

This project is a deliberate move toward mastering core development fundamentals:

Transitioning from Blueprint-based workflows to raw coding
Strengthening understanding of game architecture and logic flow
Building something functional without relying on heavy frameworks or engines

🛠️ Tech Stack
JSX — primary language for structure and game logic
JavaScript runtime (Cam-OS environment) — execution layer
Terminal interface — game entry point

🎯 Design Philosophy
Keep it lightweight
Keep it clean
Keep it controlled
